# EmailValidation

[До списку розділів](../README.md)

Методи перевірки email-адрес. Перевірка адреси електронної пошти надає докладну інформацію про працездатність email. Це дозволить виключити з надсилання неіснуючі email, знизити показник скарг, очистити список підписників і врешті-решт покращити вашу репутацію як відправника. Наприклад, ви можете інтегрувати процес перевірки у форму реєстрації вашого сайту і вже на етапі введення адреси повідомляти користувачам, що адреса, яку вони ввели у форму, недійсна.

`emailvalidation.EmailValidationAPI`, `client.EmailValidation`

| Метод | Ендпоінт | Опис |
|---|---|---|
| [`Single`](#single) | `POST /email-validation/single.json` | Допускається не більше ніж два одночасні запити; у разі перевищення буде повернуто помилку. Оскільки перевірка має бути швидкою, ми обмежуємо час, що витрачається на перевірку адреси електронної пошти. Тому, якщо ми зіткнемося з повільним поштовим сервером, час відповіді якого перевищує 5 секунд, результат перевірки може бути невідомим. |

## Single

`POST /email-validation/single.json` · [Документація](https://docs.allymailer.com.ua/ua/web-api-ref#email-validation-single)

Допускається не більше ніж два одночасні запити; у разі перевищення буде повернуто помилку. Оскільки перевірка має бути швидкою, ми обмежуємо час, що витрачається на перевірку адреси електронної пошти. Тому, якщо ми зіткнемося з повільним поштовим сервером, час відповіді якого перевищує 5 секунд, результат перевірки може бути невідомим.

### Запит: `EmailValidationSingleRequest`

| Поле | Тип | Обов'язкове | Опис |
|---|---|---|---|
| `Email` | `string` | так | Email-адреса, яку необхідно перевірити. |

### Відповідь: `EmailValidationSingleResponse`

| Поле | Тип | Опис |
|---|---|---|
| `Status` | `string` | Рядок "success". (`success`) |
| `Email` | `string` | Email, що перевіряється. |
| `Result` | `string` | Можливі статуси:<br><br>- "valid" - email-адреса дійсна,<br>- "invalid" - email-адреса недійсна,<br>- "suspicious" - email-адреса підозріла,<br>- "unknown" - адресу не вдалося перевірити. Приймаючий сервер не відповів у межах припустимого часу перевірки. |
| `Cause` | `string` | Можливі статуси:<br><br>- "no_mx_record" - у домену відсутні MX-записи,<br>- "syntax_error" - адреса не відповідає стандартам email,<br>- "possible_typo" - можливо, адресу введено з помилкою,<br>- "mailbox_not_found" - адреса не існує,<br>- "global_suppression" - адреса перманентно недоступна в сервісі через багаторазові недоставки,<br>- "disposable" - одноразовий email, зазвичай такі адреси приймають пошту лише декілька хвилин,<br>- "role" - загальна адреса електронної пошти, найчастіше використовується групою людей і не належить конкретній особі,<br>- "abuse" - адреси, з яких надходить велика кількість скарг і натискань на "спам", іноді навіть в автоматичному режимі,<br>- "spamtrap" - адреси-спам-пастки, зазвичай розміщуються поштовими провайдерами у відкритому доступі, але ніколи не використовуються для підписки. Надсилання листів на такі адреси сильно шкодить репутації відправника,<br>- "smtp_connection_failed" - SMTP-сервер недоступний — можливо, адресу введено з помилкою. |
| `Validity` | `int` | Імовірність того, що адреса дійсна. Від 0 до 100 (100 - дійсна, 0 - недійсна). |
| `LocalPart` | `string` | Локальна частина email-адреси (усе, що перед знаком "@"). |
| `Domain` | `string` | Доменна частина email-адреси. |
| `MxFound` | `bool` | Чи є у домену MX-запис? true якщо є, false якщо відсутній. |
| `MxRecord` | `string` | Бажана MX-запис домену. |
| `DidYouMean` | `string` | Можлива адреса, отримана після виправлення помилки (для cause=possible_typo). |
| `ProcessedAt` | `string` | Дата й час перевірки адреси у форматі РРРР-ММ-ДД гг:хх:сс у часовому поясі UTC. |

### Приклад

```go
package main

import (
	"context"
	"fmt"

	allymailer "github.com/allymailer/allymailer-go-sdk"
	"github.com/allymailer/allymailer-go-sdk/api/emailvalidation"
)

func main() {
	client := allymailer.NewClient("YOUR_API_KEY")

	response, err := client.EmailValidation.Single(context.Background(), &emailvalidation.EmailValidationSingleRequest{
		Email: "email@example.com",
	})
	if err != nil {
		panic(err)
	}
	fmt.Printf("%+v\n", response.Email)
}
```
